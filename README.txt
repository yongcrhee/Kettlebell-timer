KETTLEBELL COMPLEX TIMER - PHONE INSTALL

This is a Progressive Web App (PWA).

IMPORTANT:
Android/Chrome installs PWAs from a secure web address (HTTPS). Opening index.html directly from Downloads will run the timer, but Chrome normally will not offer the full "Install app" option from a local file.

EASIEST INSTALL METHOD
1. Upload the contents of this folder to any simple HTTPS web host such as GitHub Pages, Netlify, or Cloudflare Pages.
2. On your Samsung phone, open the resulting web address in Chrome.
3. Tap the Chrome menu (three dots).
4. Tap "Add to Home screen" or "Install app".
5. Confirm Install.
6. The Kettlebell Complex Timer will appear like a normal app and will work offline after the first load.

FEATURES
- Add/remove exercises
- Individual exercise durations
- Adjustable transition rest and set rest
- 3-second Get Ready
- Beeps from 10 through 4 seconds
- Spoken 3, 2, 1
- Spoken GO
- Pause / Resume / Reset
- Saves workout setup on the phone
- Offline support after installation
